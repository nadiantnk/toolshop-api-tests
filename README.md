# Toolshop API Autotests

API-автотесты для учебного сайта [Practice Software Testing](https://practicesoftwaretesting.com) (сборка с багами).
Написаны на Python с использованием pytest и requests.

## Стек

- Python 3.14
- pytest
- requests

## Что покрыто

- `GET /products/{id}` — получение товара (позитивный тест)
- `GET /products/{id}/related` — негативный тест, выявляет баг: сервер отдаёт 500 вместо 404
- `GET /brands` — получение списка брендов
- `POST /users/login` — авторизация, проверка кода и наличия токена
- `POST /users/login` — негативный тест с неверным паролем (ожидается 401)
- `POST /users/register` — регистрация нового пользователя с генерацией уникального email
- `GET /users/me` — запрос с авторизацией по токену (цепочка: логин → токен → защищённый запрос)

## Запуск

​```
pip install requests pytest
pytest
​```
## Примечание

Тест `test_related_products_not_found_returns_404` намеренно падает — он фиксирует реальный дефект приложения (500 вместо 404 на несуществующем товаре). Это демонстрация того, как автотест ловит баг.

Проект в активной разработке — набор тестов постепенно пополняется по мере изучения новых методов и сценариев.
